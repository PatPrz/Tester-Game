# Tester Game
A first-person 3D game developed in Unity as part of an engineering thesis.
The game focuses on solving logic puzzles using mechanics based on the laws of physics. Throughout the game the player explores a research facility, solves increasingly complex environmental puzzles and interacts with various objects to progress through consecutive levels.
The gameplay combines exploration, object manipulation and physics-based mechanics such as laser reflection, lever systems and liquid interaction.

## Features
- First-person gameplay
- Physics-based puzzles
- Laser reflection mechanics
- Object interaction system (pick up, move and throw)
- Interactive liquid simulation
- Pressure plates and activation systems
- Save system
- Audio and control settings
- Multiple handcrafted levels
- Custom 3D models and animations
